# Design Tokens

venomous-ui exposes CSS custom properties as the public theming API.
Use the toolbar theme switcher (top-right) to compare **light** / **dark**.

## Semantic colors

| Token                            | Light      | Dark       |
| -------------------------------- | ---------- | ---------- |
| `--venomous-color-bg`            | zinc-50    | zinc-950   |
| `--venomous-color-bg-elevated`   | zinc-100   | zinc-900   |
| `--venomous-color-fg`            | zinc-900   | zinc-50    |
| `--venomous-color-fg-muted`      | zinc-600   | zinc-400   |
| `--venomous-color-fg-subtle`     | zinc-400   | zinc-600   |
| `--venomous-color-border`        | zinc-200   | zinc-800   |
| `--venomous-color-border-strong` | zinc-300   | zinc-700   |
| `--venomous-color-accent`        | purple-600 | purple-500 |
| `--venomous-color-danger`        | red-600    | red-500    |
| `--venomous-color-success`       | green-700  | green-500  |
| `--venomous-color-warning`       | yellow-700 | yellow-500 |
| `--venomous-color-info`          | blue-600   | blue-500   |

Override the **accent triple** (`accent` / `accent-hover` / `accent-active`) to rebrand.

## Two-layer architecture

- **Palette** (`$venomous-purple-*`, `$venomous-gray-*` ...) — SCSS variables, internal only.
- **Semantic slots** (`--venomous-color-accent`, `--venomous-color-bg` ...) — CSS custom properties, the public API.

Don't reach into palette in your CSS; override semantic slots instead.
