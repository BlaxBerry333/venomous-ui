# venomous-ui

A multi-framework UI design system with a distinct visual language.

## Goals

- **One design, many frameworks.** React-first; Vue / others can be added later — the SCSS layer is framework-agnostic.
- **No headless escape hatch.** Components ship with venomous styles by design; the look _is_ the point.
- **SSR-ready.** All interactive components render correctly under Next.js / Remix / Astro.

## Install

```sh
npm install github:BlaxBerry333/venomous-ui#release
```

## Quick start (Next.js App Router)

```tsx
// app/layout.tsx
import { ThemeScript } from 'venomous-ui/react';
import 'venomous-ui/styles/reset.css';
import 'venomous-ui/styles/themes/light.css';
import 'venomous-ui/styles/themes/dark.css';

export default function RootLayout({ children }) {
  return (
    // ThemeScript sets data-theme on <html> before hydration
    <html lang="en" suppressHydrationWarning>
      <head>
        <ThemeScript />
      </head>
      <body>{children}</body>
    </html>
  );
}
```

## Switching theme

```tsx
'use client';
import { useTheme } from 'venomous-ui/react';

function ThemeToggle() {
  const { resolvedTheme, setTheme, mounted } = useTheme();
  if (!mounted) return null;
  return (
    <button onClick={() => setTheme(resolvedTheme === 'dark' ? 'light' : 'dark')}>
      {resolvedTheme === 'dark' ? '☀️' : '🌙'}
    </button>
  );
}
```

## Customize brand color

Override the semantic accent slot in your own CSS:

```css
:root {
  --venomous-color-accent: #16a34a;
  --venomous-color-accent-hover: #15803d;
  --venomous-color-accent-active: #14532d;
}
```
